MALIK PETROLEUM WEBSITE

1. Open index.html in a browser or upload the whole folder to your hosting.
2. WhatsApp number (923034306022) is set in config.js — change it there if needed.
3. The order form collects client name, phone, full delivery location, optional GPS coordinates, diesel quantity, delivery date, delivery time and additional notes. Price is not entered by the client — it is quoted by you (the provider) based on the current market rate when you confirm the order on WhatsApp.
4. On submit, the browser opens WhatsApp with a pre-filled order message.
5. For best results, host the site on HTTPS so browser geolocation works reliably.
